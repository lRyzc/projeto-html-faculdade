# Projeto de HTML básico

Projeto acadêmico criado somente com HTML, sem CSS ou JavaScript.

## Páginas

- `index.html`: apresentação pessoal, contatos, imagem e vídeo do YouTube;
- `biografia.html`: biografia, foto, hobbies, time do coração e vídeo escolhido.

## Como visualizar

Abra o arquivo `index.html` em um navegador.
