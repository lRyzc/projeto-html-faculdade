# Projeto de HTML5 básico

Atividade acadêmica desenvolvida somente com HTML5, sem JavaScript e sem folhas de estilo CSS.

## Objetivo

Praticar os fundamentos da criação de páginas web, incluindo:

- estrutura básica de um documento HTML5;
- metatags de codificação, responsividade, descrição, autoria e palavras-chave;
- títulos, parágrafos e marcações de texto;
- listas, links e navegação entre páginas;
- imagens com texto alternativo;
- incorporação de vídeos do YouTube;
- elementos semânticos do HTML5.

## Estrutura do projeto

- `index.html`: página inicial com apresentação, contatos, imagem e vídeo;
- `biografia.html`: biografia, foto, hobbies, time do coração e vídeo escolhido;
- `img/`: imagens utilizadas pelas duas páginas.

## Como visualizar

Baixe o projeto e abra o arquivo `index.html` em um navegador.
